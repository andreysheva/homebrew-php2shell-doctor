# homebrew-php2shell-doctor

Homebrew tap for [php2shell-doctor](https://github.com/andreysheva/php2shell-doctor) —
the safe checker for the php2shell PHP RCEs (CVE-2026-109618 / CVE-2026-109619).

```bash
brew install andreysheva/php2shell-doctor/php2shell-doctor
php2shell-doctor self-test
php2shell-doctor scan
```
